# SADHI — versão reorganizada

Estrutura:
- `index.html` — login
- `pages/dashboard.html` — início
- `pages/grade.html` — seleção de semestre
- `pages/horarios.html` — consulta de horários
- `pages/disciplinas.html` — gerenciamento de disciplinas
- `pages/turmas.html` — gerenciamento de turmas
- `pages/historico.html` — relatórios/histórico
- `style.css` — estilos globais
- `script.js` — interações

A interface é um protótipo front-end: os cadastros e filtros funcionam no navegador, mas a persistência real deve ser ligada ao backend/Django.
